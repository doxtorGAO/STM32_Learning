# 旋转编码器计次 —— 填空练习版 使用说明

## 一、这里面有什么

| 文件 / 文件夹 | 作用 |
|---|---|
| `练习骨架\` | 三个填空版源文件（Encoder.c / Encoder.h / main.c） |
| `_答案备份\` | 能跑的参考答案，卡住才看 |
| `用练习版.bat` | 双击它 → 把填空版装进工程 |
| `用答案版.bat` | 双击它 → 恢复答案（会先把你自己写的存到 `_我的答案存档\`） |

> `练习骨架` 里的文件**不要**在 Keil 里 "Add Existing Files" 加进工程，
> 加进去会和现有的 Encoder.c 重复定义。用 bat 替换。

## 二、接线

| 编码器模块 | 单片机 |
|---|---|
| A 相（有的模块标 CLK） | PB0 |
| B 相（有的模块标 DT） | PB1 |
| GND | GND |
| VCC（如果有） | 3.3V |

**注意**：这个工程不能调 `Key_Init()`。5-1 的 Key.c 用的 PB1 正是编码器的 B 相，
两个模块抢同一个引脚。所以 main.c 里连 `Key.h` 都没有 include。

## 三、怎么开始练

1. 双击 **`用练习版.bat`**（和 Project.uvprojx 同一层）。
2. 打开 Keil 工程，双击 `Hardware\Encoder.c` 和 `User\main.c`，会看到一排 `TODO 第 N 步`。
3. 按 `Encoder.c` 开头的顺序，**一次只填一块**，每填一块编译一次、烧录一次。

## 四、每一步该看到什么现象

| 步骤 | 填完后应该看到 |
|---|---|
| 第 1 步 写完头文件 | 编译 0 Error（没现象，正常） |
| 第 2 步 配好 PB0/PB1 输入 | 编译通过（还不能显示，正常） |
| 第 3 步 配好 EXTI0/EXTI1 | 编译通过，转动无反应 |
| 第 4 步 配好 NVIC | 同上 |
| 第 5 步 写 Get + main 显示 | 屏幕显示 `Num:    0`，转动还是 0 |
| 第 6 步 写两个中断函数 | **正转数字变大，反转变小**，停下时数字保持 |

第 5 步看到「一直是 0」是对的，它只验证显示通路通不通。第 6 步才让数字动起来。

## 五、5-2 比 5-1 难在哪

| | 5-1 对射式红外 | 5-2 旋转编码器 |
|---|---|---|
| 中断线 | EXTI14 一条 | EXTI0、EXTI1 两条 |
| 中断通道 | 1 个（EXTI15_10_IRQn） | **2 个（EXTI0_IRQn、EXTI1_IRQn）** |
| 需要调几次 NVIC_Init | 1 次 | **2 次** |
| 中断服务函数 | 1 个 | **2 个，名字不同** |
| 方向判断 | 无 | 每个中断里读另一相的电平 |
| 变量类型 | uint32_t | **int16_t（要能出负数）** |

最容易错的三处：

1. **只开了一个 NVIC 通道**。0 号和 1 号是两条独立的通道，开一个只能收到一半的边沿。
2. **两个中断函数的函数名**。必须是 `EXTI0_IRQHandler` 和 `EXTI1_IRQHandler`，
   一个字母都不能改，也不能写成 `EXTI0_1_IRQHandler` 这种。
3. **两个中断里都无条件 `++`**。那样转一格会 +2。两相各管一个方向才对。

## 六、转向判断的原理

编码器转动时，A、B 输出两路相位差 90° 的方波：

```
正转：A ─┐____      A 先降，B 后降
         B ──┐____

反转：B ─┐____      B 先降，A 后降
         A ──┐____
```

所以只要在**每个下降沿**里读**另一相**的电平：

- A 降了，B 已经是低 → B 领先 → 反转（`--`）
- B 降了，A 已经是低 → A 领先 → 正转（`++`）

这样一相只数一个方向，一次转动不会被数两次。

## 七、卡住了怎么办

| 现象 | 大概率原因 |
|---|---|
| 怎么转都不动 | 只开了一个 NVIC 通道；AFIO 时钟没开；两个 ISR 名字写错 |
| 正转变大、反转也变大 | 两个中断里都写了 `++`，没判断方向 |
| 转一格跳 +2 或 -2 | 两相都在数同一个方向；或者编码器抖动 |
| 转一格跳好几个、来回乱跳 | 中断里没做电平确认，毛刺也被数了 |
| 数字显示成很大的正数 | 用了 `OLED_ShowNum` 而不是 `OLED_ShowSignedNum` |
| 完全不显示 | main 的 `while` 里还没加显示，或者 `Encoder_Init()` 没调用 |

实在想不出来 → 对照 `_答案备份` 里的同名文件。
