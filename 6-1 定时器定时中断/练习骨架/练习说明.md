## 二、接线

**什么都不用接。** 这一课全靠芯片内部的时钟，不涉及任何外部模块。

## 三、这一课和 5-x 的本质区别

| | 5-1 / 5-2（EXTI） | 6-1（定时器） |
|---|---|---|
| 谁触发中断 | 外部引脚上的电平跳变 | 芯片内部计数器溢出 |
| 时间精度 | 取决于外部事件何时发生 | 由时钟精确决定，误差百万分之一 |
| 需要接线 | 需要 | **不需要** |
| 关键参数 | 触发边沿 | PSC、ARR |

EXTI 是「外面有动静我才动」，定时器是「时间到了我自己动」。

## 四、时间是怎么算出来的

这是这一课唯一需要动脑的地方，先算明白再填代码：

```
72 000 000 Hz  ÷  PSC  ÷  (ARR+1)  =  中断频率
```

要把中断频率做成 1 Hz：

```
72 000 000 ÷ 7200 ÷ 10000 = 1
        ↑        ↑
      PSC       ARR+1
```

- **PSC = 7200-1**：把 72MHz 分成 10kHz，也就是每 100 微秒数一个数
- **ARR = 10000-1**：数满 10000 个数就溢出一次，10000 × 100μs = 1 秒

换个频率自己算：想 500ms 一次 → ARR 改成 5000-1。想 2 秒一次 → ARR 改成 20000-1。

**为什么要 -1**：寄存器从 0 开始数。PSC 写 7199，实际是 7200 分频；ARR 写 9999，实际是数 10000 个数。都写满会慢 0.01%，肉眼看不出，但概念是错的。

## 五、每一步该看到什么现象

| 步骤 | 填完后应该看到 |
|---|---|
| 第 1 步 写完头文件 | 编译 0 Error |
| 第 2 步 main 里显示 Num | 屏幕显示 `Num: 00000`，数值不动（正常） |
| 第 3 步 开 TIM2 时钟 | 编译通过，还是 00000 |
| 第 4 步 配时基单元 | 编译通过，还是 00000（定时器还没启动） |
| 第 5 步 清更新标志 | 同上 |
| 第 6 步 开中断 + NVIC | 同上（还没启动，还是不进中断） |
| 第 7 步 写 ISR + TIM_Cmd | **数字每秒钟 +1** |

前面的步骤都没现象是正常的——定时器要等 `TIM_Cmd` 那一句才开始数，而 `TIM_Cmd` 是第 7 步才加的。

## 六、最容易错的四处

**1. 用 APB2 开 TIM2 的时钟**

```c
RCC_APB2PeriphClockCmd(RCC_APB2Periph_TIM2, ENABLE);   /* 错 */
```

`RCC_APB2Periph_TIM2` 这个宏根本不存在，编译直接报未定义。TIM2~TIM7 都在 **APB1** 上，只有 TIM1 / TIM8（高级定时器）在 APB2。

**2. 忘了 `TIM_Cmd(TIM2, ENABLE)`**

配得全对，但定时器不启动，永远不进中断，屏幕一直是 00000。这是最典型的「代码看起来没问题但没现象」。

**3. 忘了清更新标志**

`TIM_TimeBaseInit` 一执行，硬件就会置一次更新标志。不清的话，一开中断立刻进一次 ISR，**上电后 Num 从 1 开始**而不是从 0。这个 1 很难发现，得盯着屏幕看它第一次跳。

**4. 中断函数名写错**

必须叫 `TIM2_IRQHandler`。写成 `TIM2_UP_IRQHandler` 编译能过，但永远不进——启动文件里登记的是前者。

**5. 最危险的顺序问题**

先加 `TIM_Cmd`、后写中断函数 → 定时器一开始跑，第一次更新事件就跳进启动文件里的默认死循环（`B .`），**程序当场卡死**，屏幕一片空白。

所以第 7 步的顺序是：**先把 `TIM2_IRQHandler` 写完，再回 `Timer_Init` 末尾加 `TIM_Cmd`**。

## 七、卡住了怎么办

| 现象 | 大概率原因 |
|---|---|
| 一直是 00000，不动 | 忘了 `TIM_Cmd`；或中断函数名写错；或 NVIC 没开 |
| 上电就是 1 然后每秒加 | 没清更新标志（少了 `TIM_ClearFlag`） |
| 一下跳好几十 | PSC/ARR 算错了，量级差太多 |
| 程序卡死、屏幕空白 | 先加了 `TIM_Cmd`，中断函数还空着 |
| 编译报 `RCC_APB2Periph_TIM2` 未定义 | 时钟用错了总线，改成 APB1 |
| 数字每秒跳 2 次 | ARR 少除了一个 2，检查计算 |
