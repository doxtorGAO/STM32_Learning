# 对射式红外传感器计次 —— 填空练习版 使用说明

## 一、这里面有什么

| 文件 / 文件夹 | 作用 |
|---|---|
| `练习骨架\` | 三个填空版源文件（CountSensor.c / CountSensor.h / main.c） |
| `_答案备份\` | 你原来那份能用的答案，原样保存，别删 |
| `用练习版.bat` | 双击它 → 把填空版装进工程 |
| `用答案版.bat` | 双击它 → 恢复答案（会先把你自己写的存档） |

> 注意：`练习骨架` 里的文件**不要**在 Keil 里"Add Existing Files"加进工程，
> 加进去会和现有的 CountSensor.c 重复定义、报一堆错。
> 正确做法就是用下面这两个 bat 脚本替换工程里的文件。

## 二、怎么开始练

1. 双击 **`用练习版.bat`**（就在工程根目录，和 Project.uvprojx 同一层）。
2. 打开 Keil 工程，双击 `Hardware\CountSensor.c` 和 `User\main.c`，
   会看到一排 `TODO 第 N 步`。
3. 按 `CountSensor.c` 文件开头写的顺序，**一次只填一块**，
   每填一块就 **编译一次 + 烧录一次**，确认现象对了再填下一块。

## 三、每一步该看到什么现象

| 步骤 | 填完后应该看到 |
|---|---|
| 第 1 步 写完头文件 | 编译 0 Error（什么现象都没有，正常） |
| 第 2 步 配好 PB14 输入 | 打开 main.c 里第 2 步的自测行 → 手没挡=1，挡住=0 |
| 第 3 步 配好 EXTI | 编译通过（还没写中断函数，所以还不计数） |
| 第 4 步 配好 NVIC | 同上 |
| 第 5 步 写中断函数 | 遮一次光，数字 +1（可能一次跳好几个，正常，下一步解决） |
| 第 6 步 加消抖 | 遮一次只 +1，很稳 |
| 第 7 步 加按键 | 按 KEY1，数字归零 |

## 四、卡住了怎么办

先看这几个提示：

- 挡住屏幕毫无反应 → 按"AFIO 时钟 / 触发边沿 / 函数名 / NVIC"四项挨个查。
- 数字疯涨或程序像卡住 → 中断里忘了 `EXTI_ClearITPendingBit`。
- 遮一次跳好几个数 → 还没做第 6 步的消抖。
- 编译报 `undefined symbol` → 文件没加进 Keil 的 Hardware 分组。
- 实在想不出来 → 对照 `_答案备份` 里的同名文件，
  或者把代码贴给我，我帮你逐行看。

## 五、练完想换回答案

双击 **`用答案版.bat`**。
它会先把你写的三个文件存到 `_我的答案存档\`，再装回参考答案，不用担心白写。
